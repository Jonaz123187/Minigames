# GiG-Spielcover

Erzeugt mit der eingebauten Bildgenerierung. Redaktionelle Illustrationen, keine Spiel-Screenshots. Die ersten acht Dateien wurden auf 1120 × 630 Pixel exportiert und als WebP komprimiert. Alte Spiel-IDs bleiben erhalten; nur Anzeigenamen und Bildpfade ändern sich.

## Gemeinsamer Prompt

```
Use case: stylized-concept. Asset type: finished wide 16:9 game thumbnail for the GiG friends' browser arcade. Create a single polished game-cover illustration, 1536x864 landscape composition. Visual system: deep ink-navy backdrop (#101927), restrained thin blue grid accents, chunky clean voxel/pixel-inspired shapes, flat shaded faces with crisp edges, mint green (#b5f36a), lavender (#aa97ff), warm ivory, small coral and cyan accents. High contrast, tasteful soft ambient lighting, playful but premium. Large readable central silhouette fills about 65 percent of the frame; generous margins for cropping; supporting details subordinate. This is illustrative cover art, not a screenshot. No lettering, numbers, logos, UI, watermark, border or collage.
```
