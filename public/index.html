Regeln & Technik

Normalmodus: Platz 1/2/3 gibt 10/7/5 Arcade-Punkte, weitere Plätze 2. Gleichstände teilen den Platz. Training gibt keine Arcade-Punkte. Nach jeder Runde landet ihr automatisch wieder in der Lobby. Punkte bleiben für diese Sitzung; beim Verlassen oder Server-Neustart werden sie nicht gespeichert.

Bei Verbindungsabbruch wird die Teilnahme aufgegeben. Bleibt in einer normalen Runde nur eine Person, wird sie ohne Wertung beendet. Der Host wechselt automatisch. Reaktions- und Rhythmuswertungen werden beim Server gemessen; die Verbindung kann das Ergebnis beeinflussen.

Dub Studio vergleicht Rhythmus, Lautstärkeverlauf und relative Tonhöhe. Es bewertet keine Worterkennung oder Stimmidentität. Audio wird ausschließlich mit der aktuellen Lobby geteilt und nicht auf dem Server dauerhaft gespeichert. Mikrofonzugriff benötigt HTTPS oder localhost und deine Browser-Freigabe. Nutzt für importierte Clips eigene oder freigegebene Vorlagen.
